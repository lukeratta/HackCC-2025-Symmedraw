# Symmedraw - (HackCC 2025 Submission)

Symmedraw is a drawing application with the following features:
- A pencil
- An eraser
- The symmetry pencil
- A size slider
- A color selector
- A rainbow color option
- A custom color selector
- The ability to export your created image

The main feature of Symmedraw is the symmetry pencil. It allows the user to draw multiple things at once, mirrored around a central axis. The user is able to choose how many times their drawing is mirrored and can change it at will.
